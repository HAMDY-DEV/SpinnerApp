Spinner App

A simple Android application built with Kotlin that uses a Spinner to display a list of anime titles.

Features

Display anime names in a Spinner.

Select an anime from the list.

Open a Google search for the selected anime.

Select Anime
     ↓

     ↓
Google Search

When the user selects an anime, the app opens Google and searches for that anime.

Run

Open the project in Android Studio and run it on an emulator or Android device.
